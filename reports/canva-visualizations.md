# Interactive Visualizations — Canva

## Clustering Analysis Visualization

This repository's clustering analysis has been presented in an **interactive Canva presentation**.

**Link:** [Taylor Swift Cluster Analysis (Canva Design)](https://canva.link/38t4cvu6be8yynr)

### What's Included

- **Overview:** Album eras and stylistic evolution
- **Dendrograms:** Hierarchical clustering visualization
- **K-Means scatter plots:** 2D/3D representations of clusters
- **Audio feature comparisons:** Box plots and violin plots by album
- **Feature importance:** Which audio features matter most
- **Cluster profiles:** Detailed description of each cluster
- **Temporal trends:** How Taylor's sound has evolved
- **Interactive elements:** Hover for details, zoom capability

### Design Features

- Color scheme matches Taylor's album era colors
- Professional academic aesthetic
- Fully interactive (navigable on Canva)
- Export-friendly (PDF, PNG, video formats available)

## Notes for Viewers

- Visualization reflects analysis of 147 Taylor Swift songs (11 albums)
- Clustering based on 8 Spotify audio features
- Hierarchical + K-Means methods applied
- Results validated using silhouette analysis and Dunn index
